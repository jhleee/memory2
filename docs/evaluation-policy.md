# 평가 실행과 자료 보존

공개 저장소에는 평가 스크립트와 합성 fixture를 제공합니다. 상세 보고서, 모델 응답, 실행 메타데이터와 바이너리 근거 자료는 공개 업로드의 자동 승인 검토에서 차단되어 포함하지 않았습니다. 원본은 이관 전 작업 디렉터리에 보존되어 있습니다.

과거 문서의 관련 링크는 이 안내로 연결했습니다. 로컬 실행 결과와 저장 DB는 Git에 올리지 않습니다. 오프라인 실행 절차는 [평가 안내](../evaluation/README.md), 공개한 구현 한계는 [수정 계획](known-issues.md)을 확인하세요.

저장 무결성, 서사 정합성과 인간의 재미는 다른 평가 대상입니다. AI 페르소나 결과를 인간 장기 플레이의 검증으로 주장하지 마세요.
